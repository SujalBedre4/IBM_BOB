# AutoRelease Guard Release Artifacts

This directory is populated by the `pr-artifact-gen` subagent.

| File | Description |
|------|-------------|
| `RELEASE_NOTES.md` | Keep-a-Changelog formatted release notes |
| `ROLLBACK_RUNBOOK.md` | Step-by-step rollback commands with smoke tests |
| `DEPLOY_CHECKLIST.md` | Sign-off checklist for deployment window |

These artifacts are intended to accompany the deployment package and be shared with
the release engineer and on-call SRE before the deployment window opens.

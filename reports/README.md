# AutoRelease Guard Pipeline Reports

This directory is populated automatically by the AutoRelease Guard pipeline.

| File | Generated By | Description |
|------|-------------|-------------|
| `security.sarif.json` | sec-auditor | SARIF 2.1.0 security findings |
| `infra-check.json` | infra-validator | Infrastructure lint report |
| `coverage-gaps.json` | test-synthesizer | Coverage gap analysis |
| `release-readiness.json` | release-planner | Final GO/NO-GO verdict |

Do not commit these files. Add `reports/` to `.gitignore` (except in CI artifact uploads).

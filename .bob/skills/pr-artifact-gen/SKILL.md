# PR Artifact Generator Skill

Consume the three subagent reports and produce the complete release deployment package.
All three reports must exist before this skill runs.

---

## Step 1 — Load and Validate Input Reports

Read each report and confirm they are valid and complete:

```
reports/security.sarif.json   → x-autorelease-summary.blocked must exist
reports/infra-check.json      → blocked field must exist
reports/coverage-gaps.json    → tests_generated array must exist
```

Also read:
- `AGENTS.md` for microservice context and rollback requirements
- `git log origin/main...HEAD --oneline` for commit list (use `execute_command`)
- `git diff origin/main...HEAD --stat` for changed file summary

---

## Pre-Rollback Checklist

Before executing rollback, confirm:

- [ ] Production incident confirmed and severity assessed (P1/P2/P3)
- [ ] Rollback decision approved by on-call lead
- [ ] Current deployment SHA noted: `kubectl get deployment <name> -o jsonpath='{.spec.template.spec.containers[0].image}'`
- [ ] Database migration status checked (see section below)
- [ ] Downstream services and consumers notified

---

## Rollback Commands

### api-gateway (Node.js — Port 3000)

```bash
# Step 1: View rollout history
kubectl rollout history deployment/api-gateway -n production

# Step 2: Rollback to previous version
kubectl rollout undo deployment/api-gateway -n production

# Step 3: Monitor rollback progress
kubectl rollout status deployment/api-gateway -n production --timeout=5m

# Step 4: Verify pods are healthy
kubectl get pods -n production -l app=api-gateway
```

### worker-service (Python — Port 8080)

```bash
kubectl rollout undo deployment/worker-service -n production
kubectl rollout status deployment/worker-service -n production --timeout=5m
kubectl get pods -n production -l app=worker-service
```

### metrics-exporter (Go — Port 9090)

```bash
kubectl rollout undo deployment/metrics-exporter -n production
kubectl rollout status deployment/metrics-exporter -n production --timeout=5m
```

## Smoke Test (Post-Rollback Verification)

Run after rollback to confirm the previous version is healthy:

```bash
#!/bin/bash
set -e

echo "=== AutoRelease Guard Smoke Test ==="

# api-gateway health check
STATUS=$(curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/health)
[ "$STATUS" = "200" ] && echo "✅ api-gateway healthy" || echo "❌ api-gateway UNHEALTHY (status: $STATUS)"

# worker-service health check
STATUS=$(curl -s -o /dev/null -w "%{http_code}" http://localhost:8080/health)
[ "$STATUS" = "200" ] && echo "✅ worker-service healthy" || echo "❌ worker-service UNHEALTHY (status: $STATUS)"

# metrics-exporter health check
STATUS=$(curl -s -o /dev/null -w "%{http_code}" http://localhost:9090/metrics)
[ "$STATUS" = "200" ] && echo "✅ metrics-exporter healthy" || echo "❌ metrics-exporter UNHEALTHY (status: $STATUS)"

echo "=== Smoke test complete ==="
```
